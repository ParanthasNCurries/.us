PARANTHAS & CURRIES — FREE WEBSITE STARTER

Files:
- index.html: website content and page structure
- style.css: colors, layout, and responsive styling

Before publishing:
1. Open index.html in a text editor.
2. Replace YOUR-EMAIL-HERE with your business email address.
3. Replace YOURWHATSAPPNUMBER with your WhatsApp number in international digits only (US example: 1XXXXXXXXXX).
4. Check the menu text, service area, and any permit/inspection wording. Do not publish details that aren't accurate.
5. Add your real food photographs when ready.

Publish for free with Cloudflare Pages:
1. Create a Cloudflare account at https://dash.cloudflare.com/sign-up
2. Open Workers & Pages and create a Pages project.
3. Upload this folder's files using the upload/static-site option if offered. If the dashboard only offers Git integration, follow the Git-based deployment route instead.
4. Cloudflare will provide a free *.pages.dev address.
5. A custom .com domain is optional and usually has an annual registration fee.

Notes:
- Hosting can be free; a custom domain is usually not free.
- This starter site uses email/WhatsApp inquiry buttons, not an online card checkout.
- Google Fonts are loaded externally; if you want no external requests, remove the @import line in style.css.
